ПРИМЕР: упаковка программы hello.sh в RPM (5 минут)
=====================================================

1. Запустите RPM Builder и в панели слева нажмите
   «Открыть из файла…» → выберите hello.rpmb.json ПРЯМО ИЗ ЭТОЙ ПАПКИ.

   С версии 1.4.1 копировать hello.sh в домашний каталог НЕ нужно:
   файл подхватится из папки шаблона автоматически (появится тост
   «файлы взяты из папки шаблона: hello.sh»).

   Форма заполнится автоматически: имя hello, версия 1.0,
   зависимость bash, скрипт %post, файл hello.sh → %{_bindir}.

2. Страница «Сборка» → кнопка «Собрать пакет».

   Не собирает и пишет «rpmbuild не найден»? Установите утилиту:
       sudo dnf install rpm-build      (РЕД ОС / RHEL)
       sudo apt install rpm            (Astra / Debian / Ubuntu)
   и нажмите «Проверить снова» на странице «Сборка».

   Готовый пакет появится в ~/rpmbuilder-output:
       hello-1.0-1.*.noarch.rpm

3. Установите и проверьте:

       sudo dnf install ~/rpmbuilder-output/hello-1.0-1.*.noarch.rpm
       hello.sh

4. Удаление:

       sudo dnf remove hello

Файлы примера:
  hello.sh         — «программа» (обычный shell-скрипт)
  hello.rpmb.json  — шаблон проекта для RPM Builder
  hello.spec       — эталонный SPEC (что генерирует RPM Builder)
