ПРИМЕР: сборка RPM из исходников — программа на C (10 минут)
=============================================================

Отличие от примера hello: здесь программа не готовая, а КОМПИЛИРУЕТСЯ
gcc прямо во время сборки пакета. Точно так же собираются проекты
на Rust (cargo build), Go (go build), C++ и anything-make.

1. Убедитесь, что есть компилятор (на РЕД ОС он обычно есть):

       gcc --version   ||  sudo dnf install gcc

   С версии 1.4.1 копировать main.c в домашний каталог НЕ нужно:
   при открытии hello-c.rpmb.json исходник подхватится из папки
   шаблона автоматически.

2. Запустите RPM Builder и в панели слева нажмите
   «Открыть из файла…» → выберите hello-c.rpmb.json
   из этой папки.

   Форма заполнится автоматически: имя hello-c, архитектура x86_64,
   BuildRequires: gcc, и три новые секции на странице
   «Скрипты и сборка»:

       %build    cd %{_sourcedir}
                 gcc -O2 %{_sourcedir}/main.c -o hello-c

       %install  install -Dm755 %{_sourcedir}/hello-c
                              %{buildroot}%{_bindir}/hello-c

       %files    %{_bindir}/hello-c

3. Страница «Сборка» → кнопка «Собрать пакет».

   В логе видно, как rpmbuild выполняет %build (компиляцию),
   затем %install. Готовый пакет появится в ~/rpmbuilder-output:
       hello-c-1.0-1.*.x86_64.rpm

4. Установите и проверьте:

       sudo dnf install ~/rpmbuilder-output/hello-c-1.0-1.*.x86_64.rpm
       hello-c

5. Удаление:

       sudo dnf remove hello-c

КАК СОБИРАТЬ РУСТ/ГО/ДРУГОЙ ЯЗЫК (те же 3 шага в GUI)
-----------------------------------------------------
1. «Файлы»: добавьте ПАПКУ своего проекта целиком (например ~/myapp).
2. «Зависимости»: в BuildRequires добавьте toolchain — cargo или golang.
3. «Скрипты и сборка»:
   - вкладка %build:
       cd %{_sourcedir}/myapp
       cargo build --release            (Rust)
       go build -o myapp ./cmd/myapp    (Go)
   - вкладка %install:
       install -Dm755 %{_sourcedir}/myapp/target/release/myapp \
           %{buildroot}%{_bindir}/myapp
   - вкладка %files:
       %{_bindir}/myapp
4. «Сборка» → «Собрать пакет» — готово.

Примечания:
- если секции %install/%files заданы, авто-копирование файлов
  отключается — вы полностью управляете содержимым пакета;
- секции сохраняются в JSON-шаблоне и в истории проектов;
- в простом режиме (секции пустые) всё работает как раньше:
  добавленные файлы просто кладутся в пакет без компиляции.
