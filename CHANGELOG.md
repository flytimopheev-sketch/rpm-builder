# CHANGELOG

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.4.1] — 2026-10-15

Главный корень сбоев сборки на реальных машинах найден воспроизведением и устранён:
**пробел в пути рабочей папки** (`~/.local/share/rpm-builder/RPM Builder/workspace`)
ломал раскрытие путей в макросах rpmbuild (`%mkbuilddir`, rpm-tmp) — не собирался
ни один проект, включая встроенные примеры.

### Исправлено
- Сборка на реальных системах (РЕД ОС и др.): рабочая папка перенесена в
  `~/.local/share/rpm-builder/workspace` — путь без пробелов
- Ошибки rpmbuild больше не терялись: stderr не читался вовсе — теперь
  `QProcess::MergedChannels`, журнал полнее, карточка «Почему сборка не удалась»
  собирает строки ошибок
- SPEC передаётся в rpmbuild по абсолютному пути (раньше — относительный,
  что давало «Failed to stat … No such file»)
- `FailedToStart` у QProcess обрабатывается: понятный лог + команды установки
  вместо вечного «идёт сборка»
- «Отменить» в сборке: SIGTERM, затем SIGKILL через 2.5 с; отдельный тост
  «Сборка отменена» вместо ложной «ошибки сборки»; статус rpmbuild
  перепроверяется при каждом запуске
- Примеры hello / hello-c собираются сразу после открытия шаблона: файлы-тёзки
  автоматически подставляются из папки шаблона

### Добавлено
- Сквозной тест `--e2etest [шаблон]`: открытие примера из папки → загрузка →
  сборка **настоящим** rpmbuild (проверено на hello и hello-c)
- Карточка «rpmbuild не найден» с командами установки (`dnf install rpm-build`
  / `apt install rpm`) и кнопкой «Проверить снова»

## [1.4.0] — 2026-10-14

Системные диалоги QtQuick (FileDialog/FolderDialog) молча не открывались
на части окружений (Wayland/порталы/темы РЕД ОС) — из-за этого не работали
«Добавить папку/файлы», «Сохранить как» и др. Drag&drop оставался рабочим.

### Изменено
- Полностью убраны QtQuick.Dialogs: новый встроенный компонент **FilePicker** —
  оверлей внутри окна (режимы выбора файлов/папки/сохранения, адресная строка,
  быстрые места, скрытые файлы, мультивыбор, авто-расширение `.spec`)
- Отмена сборки: `cancelBuild()` = SIGTERM → через 2.5 с SIGKILL
  (раньше `kill()` мог не завершить rpmbuild)

### Добавлено
- Разбор ошибок сборки: строки ошибок захватываются из журнала (до 12, без дублей),
  карточка «Почему сборка не удалась» + эвристические подсказки
- Тесты `--picktest` и `--canceltest`

## [1.3.0] — 2026-10-05

### Добавлено
- Сборка проектов **Rust / Go / C / make из исходников**: секции
  `%build` / `%install` / `%files`, BuildRequires для toolchain
- Страница «Скрипты и сборка»: 7 вкладок с примерами и подсказками
- Пример [hello-c](docs/examples/hello-c/) — компиляция C внутри `%build`

### Исправлено
- `setScript()` молча игнорировал новые ключи (build/install/files) —
  первый ввод не сохранялся; JSON-roundtrip расширен на все секции

## [1.2.0] — 2026-09-06

### Добавлено
- Окно «О программе» (версия, назначение, требования, лицензия)

### Исправлено
- Значения текстовых полей («Имя пакета», «Версия», «Релиз», …) сбрасывались
  при изменении других полей — компоненты не подавали сигнал `textEdited`
- Кнопки окна (свернуть/развернуть/закрыть) прижаты к правому верхнему углу
- Выпадающие списки «Архитектура»/«Лицензия» обновляются после загрузки шаблона

## [1.1.0] — 2026-08-31

### Добавлено
- JSON-шаблоны проектов `*.rpmb.json`: «Сохранить в файл…» / «Открыть из файла…»,
  переносимы, пути `~/...` раскрываются на машине, где шаблон открывают
- CI (GitHub Actions): сборка в контейнере Fedora + оффлайн-самопроверка
- SPEC для упаковки самого приложения в RPM
- Руководство пользователя (PDF, RU)

### Изменено
- Совместимость расширена до glibc ≥ 2.34 (РЕД ОС 8 и другие старые дистрибутивы)

## [1.0.0] — 2026-08-26

Первый релиз.

### Добавлено
- Безрамочное окно (X11/Wayland), тёмная и светлая темы
